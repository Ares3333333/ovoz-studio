## Что это
Быстрый продукт уровня Apple на узбекском рынке: **автосубтитры, AI-даббинг uz↔ru↔en, перевод документов**. Стек: FastAPI + vanilla JS SPA (никаких фреймворков) + Telegram Mini App + PWA. SQLite (WAL). 823 теста pytest + статические гейты.

## Сделано (проверено реальными прогонами, не «на глаз»)
### Ядро / моат
- **Локальный ASR без ключей и облаков**: faster-whisper int8 CPU, офлайн после кэша модели; cpu_threads + семафор слотов (замер: без них ASR глушит event loop).
- **10 голосов на язык** (5F+5M): uz = Madina/Sardor + DSP-персоны ffmpeg (asetrate/atempo), ru/en = реальные edge-tts голоса; список верифицирован TTS→ASR-оракулом (`probe-data/voice_oracle.py`) — какие голоса реально читают какой язык.
- Собственные линг-движки (романизатор 2026-алфавит, Nafis, Qator, Jimlik-выравнивание, So'z-тайминги, cut-law) — `/api/v1/ling/*`, с fail-open kill-switch флагом.
- Даббинг-пайплайн: mixer-слоты, абсолютный потолок 900с, ретраи транзиентных TTS-отказов, честные события.
- Стриминг-загрузка на сервер (`_spool_upload`, медиа-лимит 64MiB — раньше 4MiB делал продажу длинных тасков невозможным).

### Деньги и надёжность
- Инварианты: CAS-переходы статусов, debit-before-claim в retry, per-row CAS в recover_stale_jobs, возврат⇔списание, самопочинка начислений платежей, рефанд при shutdown.
- SSRF-защита вебхуков (`safe_webhook_url` + NoRedirect + перепроверка при каждой попытке).
- **Feature-флаги = настоящие kill-switch'и** (раунд 42): 4 эндпоинта гейтятся до план-логики, миграция устаревших дефолтов, тест-гейт «нет декоративных флагов».
- RAM-форензика: пик длинного даббинга 1.07GB (замер) → docker 2GB, OVOZ_DUB_SLOTS=1; отчёт `docs/MEMORY_AUDIT_v0.30.md`.

## Конвенции (нарушение = откат)
1. Версия в 3 местах синхронно: `app/__init__.py`, `BUILD` в `static/sw.js`, `?v=` в `static/index.html` (иначе SW отдаёт старый бандл). Править через `[IO.File]::WriteAllText` с литеральными путями.
2. Статические гейты в `tests/test_frontend_invariants.py` — каждый фикс оставляет тест-замок с цитатой инцидента в docstring.
3. PowerShell: никогда инлайн-`$` через мост агента (ломается) — только файлы-скрипты или Python. Кириллица в .ps1 иногда валит парсинг.
4. git: `-c user.name='Ovoz Studio' -c user.email='dev@ovoz.localhost'` на каждую команду; conventional commits; `.env` не коммитить.
5. Прогон-цикл раунда: фикс → тесты → бамп → рестарт → verify через туннель → коммит+тег→ пуш master+main.
