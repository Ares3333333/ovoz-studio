# Анализ рынка и выбор ниши — Ovoz AI Studio

Дата исследования: сентябрь 2026. Источники: веб-поиск (Exa/Jina), сайты конкурентов,
IT Park / startupbase.uz, отчёты OECD/UNESCAP по цифровизации Узбекистана.

## 1. Макрокартина Узбекистана

- Население ~37 млн, медианный возраст ~29; официальный язык — узбекский,
  делопроизводство и госсектор переведены на узбекский (латинская графика).
- Быстрый рост интернет-проникновения; доминирующие каналы commerce —
  Telegram и Instagram; платежи — Payme/Click/Uzum; огромная диаспора трудовых
  мигрантов в России (сотни тысяч – миллионы) и Казахстане.
- Государство субсидирует IT (IT Park, налоговые льготы, Digital Startup Awards),
  венчурный фонд IT Park Ventures финансирует языковые AI-проекты.

## 3. Найденные СВОБОДНЫЕ дыры (валидированы фактами)

1. **YouTube Auto-Dubbing поддерживает ~30 языков — узбекского, казахского,
   кыргызского НЕТ.** Глобальные платформы даббинга (ElevenLabs и т.п.) тоже
   не покрывают узбекский массово. При этом вертикальное видео на узбекском
   (Telegram-каналы, YouTube, Reels/Shorts) растёт взрывно.
2. **Whisper и крупные ASR плохо работают с узбекским** — язык классифицирован
   как low-resource; локальные проекты (uz-speech, Aiphoria) — это research/нишевые
   банковские POC, а не массовый продукт. Проблемы: код-смешинг с русским,
   кириллица↔латиница, разные стандарты апострофа (ʻ ’ `).
3. **Перевод документов uz↔ru — оплачиваемый офлайн-рынок без цифрового продукта**:
   бюро в Москве берут 360–925 ₽/страница + нотариальное заверение; в Ташкенте —
   аналогично. Клиенты: мигранты (патент, РВП, договоры), SME (договоры, тендеры,
   реестры), суды/нотариусы. Очередь, срочность, цена — классические признаки
   готовности платить онлайн.

## 4. Выбранная ниша

**Языковая AI-инфраструктура для тюркских low-resource языков (узом)**:
субтитры, даббинг и перевод документов uz↔ru↔en для:
- **B2C**: креаторы, SMM-щики, eduplatforms, мигранты (документы);
- **B2B**: медиа, рекламные агентства, онлайн-школы, юрфирмы.

Почему это «не банальщина» и не занятая ниша:
- Это не CRM, не маркетплейс-тулза, не «ещё один чат-бот для бизнеса».
- Глобальные игроки (YouTube/Google/HeyGen) **не могут** закрыть low-resource
  языки быстро — нужен локальный data-контур; локальные игроки (Aiphoria и пр.)
  не делают продукта для массового self-service.

## 5. Ров (защита)

1. **Языковые данные**: транслитерация кириллица↔латиница, единый апостроф,
   code-switching uz/ru, локальные термины — реализовано в MVP как отдельный слой.
2. **Глоссарии клиентов** (бренды, юртермины) — накапливаются и удерживают B2B.
3. **Локальные платежи** (Payme/Click/uzum + Telegram Stars для диаспоры/мира).
4. **Дистрибуция через Telegram Mini App** — там, где живёт аудитория.
5. Сетевой эффект: каждый скачанный SRT/ROL «сделано Ovoz» — реклама.

## 7. Риски

- Качество ASR по узбекскому в демо-режиме — ниже продакшн: требуется дообучение
  (собран дата-контур пайплайна, модель подключается через адаптер).
- Юридическая ответственность за перевод документов: MVP позиционируется как
  «черновик + верификация человеком/нотариусом партнёра», не финальный легализованный перевод.
- Платёжные интеграции требуют статуса (ИП/IT Park резидентство) — см. GTM.
